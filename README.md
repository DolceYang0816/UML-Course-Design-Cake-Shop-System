## UML-Course-Design-Cake-Shop-System

An undergraduate UML modeling project for analyzing and designing
an online cake shop system.

### Course Information

- Course: Unified Modeling Language (UML)
- School: School of Computer Science and Technology
- Major: Internet of Things Engineering
- Level: Undergraduate
- Semester: Year 2 Semester 2
- Grade: 99

### Project Overview

This project applies UML methods to model an online cake shop system.

### Models

The project includes:

- Business Model
- Requirement Model
- Analysis Model
- Design Model
- Implementation Model
- Deployment Model

### Modeling Tool

- Enterprise Architect

### Files

- `.qea` : Enterprise Architect project file
- `.xml` : Exported UML model file
